University Student Performance Database

A MySQL project for managing and analyzing student performance and training data.

Project Description

This project is designed to manage information about students, departments, courses, grades, and training.

It also includes SQL queries to analyze student performance and generate organized reports.

Database Tables

* Departments
* Students
* Courses
* Grades
* Training

SQL Features Used

* JOINs
* Subqueries
* Aggregate Functions
* GROUP BY
* Views

Reports

The project includes:

* Student performance report
* Training report
* Average grades for students
* Average grades for courses
* Highest and lowest grades
* Students with GPA above the overall average

Technology

* MySQL
